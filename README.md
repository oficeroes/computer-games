# 《命运之契》：Python 文字 RPG

这是一个在终端运行的回合制文字游戏。仓库现有主程序包含角色创建、职业选择、回合战斗、背包、商店、剧情对话和随机事件等实现；详细设定见 [游戏介绍](游戏介绍.md)。

## 运行

在支持 Python 的终端中运行：

```bash
python destiny_bonds_rpg.py
```

游戏通过文字提示接收输入。上述命令来自仓库现有介绍文档，本 README 未记录跨平台运行测试结果。
